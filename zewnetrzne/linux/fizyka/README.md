# Fizyka gier 2D

Ten katalog jest pakietem duck `fizyka`, moduły są w `src/`. Do pierwszego
programu importuj `fizyka.start`, do dodatkowych operacji `fizyka.gra`.
Pakiet jest w całości w Ducklingu i nie wymaga kodu C.

Pierwsza instrukcja i karty funkcji znajdują się w dokumentacji.
[Pierwsze kroki](../dokumentacja/fizyka/PIERWSZE-KROKI.md),
[API](../dokumentacja/fizyka/API.md).
